# Game Delistings Tracker

This is a Docker-ready Next.js scaffold for the delistings project.

## Run with Docker

```powershell
docker compose up --build
```

Open `http://localhost:3000`.

## Initialize Git (PowerShell.exe)

From this folder, run:

```powershell
powershell.exe -NoProfile -Command "git init; git add ."
```
